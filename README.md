# matthiasbirkich.github.io
Android-Chrome web app for nRF52840sense and nRF52840 logger 

there are two versions for firmware v41 and for firmware v46 (added BMA400 and AS7343)

The Chrome webApp is only running on Android and PC, because iOS is not supporting web BLE

Funktion Test: Connect → STATUS → BMA_CHECK → AS_CHECK → MEAS → COUNT afterwards setting the time interval      		   and START logging.
