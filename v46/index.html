ReefCube BLE Logger · v46

Chrome Web Bluetooth controller for XIAO nRF52840 / Sense, external BMA400, AS7343, XIAO Logger HAT. Uses ReefCube custom 128-bit GATT service (not Nordic UART).

Disconnected

Connection

Only loggers advertising a name starting with UW52840-RC46 are shown. Connect while the logger is awake and advertising. On Android, use Chrome. Web Bluetooth requires HTTPS or localhost.

Quick checks

Logging

Intervals are sent explicitly in minutes. Do not use SETINT 1 with v46 (that command expects seconds).

Time and deployment

RTC is set using the computer's current local date and time (no automatic timezone conversion). Verify the time afterward.

Export data

CSV is streamed in 20-byte BLE notifications. Keep the logger connected until CSV_END appears. The app saves a CSV file locally in your browser's downloads.
